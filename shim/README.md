# safeeasyapi has moved to oathkey

This package was renamed. It only installs `oathkey` and prints where to go.

```
pipx install oathkey
```

Nothing is migrated from the old name: re-run `oathkey get <service>` for each key and `oathkey install` for your AI tools, and remove the old `safeeasyapi` hook and MCP entries from their settings.

Project: https://github.com/calasdan-sketch/oathkey
